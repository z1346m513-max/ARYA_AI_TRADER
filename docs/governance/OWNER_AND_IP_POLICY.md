# سیاست مالکیت، اختیار و مالکیت فکری

## مالک پروژه
- GitHub repository owner: `ziya1346`
- تصمیم نهایی محصول و پذیرش تغییرات: مالک پروژه.

## سیاست مشارکت
مشارکت‌کنندگان برای کار در پروژه باید شرایط همکاری و مالکیت فکری تعیین‌شده توسط مالک پروژه را بپذیرند. هیچ مشارکت‌کننده‌ای مجاز نیست از کد، داده، مستندات یا خروجی‌های اختصاصی پروژه خارج از مجوزی که مالک پروژه تعیین کرده استفاده کند.

## واگذاری حقوق
برای اینکه ادعای «کپی‌رایت صرفاً متعلق به مالک پروژه است» از نظر قراردادی قابل اتکا باشد، قرارداد همکاری/واگذاری حقوق باید با مشارکت‌کنندگان تنظیم و امضا شود. این مخزن سیاست عملیاتی پروژه را ثبت می‌کند، اما به‌تنهایی جایگزین قرارداد حقوقی لازم‌الاجرا نیست.

## ممنوعیت
- کپی یا انتقال کد/دادهٔ اختصاصی به پروژهٔ دیگر بدون اجازهٔ مالک.
- واردکردن کد شخص ثالث بدون بررسی license و ثبت منبع.
- واردکردن کد تولیدشده توسط AI بدون بررسی source/evidence/license.
- commit کردن secrets یا اطلاعات دسترسی.

## پذیرش
هر PR مشارکت‌کننده باید با سیاست‌های مالکیت و مجوزهای پروژه سازگار باشد؛ موارد مبهم باید قبل از merge به مالک پروژه ارجاع شوند.
