# دفتر ثبت تغییرات و شواهد

این فایل شاخص رسمی Change Recordهاست. هر تغییر معنادار باید یک رکورد مستقل در docs/changes/ داشته باشد.

## قالب وضعیت
- **PROPOSED:** پیشنهاد ثبت شده ولی هنوز اجرا نشده.
- **IMPLEMENTED:** اجرا شده و شواهد/تست ثبت شده.
- **BLOCKED:** به دلیل نبود شواهد یا مانع فنی متوقف شده.
- **REJECTED:** توسط مالک پروژه رد شده.
- **SUPERSEDED:** با تصمیم جدید جایگزین شده.
