# فیلترها و استراتژی‌ها

قابلیت‌های این بخش از الگوهای عمومی مشاهده‌شده در منابع فیلترنویسی بورس،
نقشه‌های بازار و سامانه‌های پایش لحظه‌ای الهام گرفته‌اند؛ کدهای سایت‌های ثالث
مستقیماً کپی نشده‌اند و هیچ‌کدام به‌تنهایی سیگنال قطعی خرید/فروش نیستند.

## فیلتر بازار

`arya.scanner.filters` شروط قابل‌آزمون زیر را فراهم می‌کند:

- درصد تغییر قیمت در بازهٔ مجاز
- تأیید حجم نسبت به میانگین تاریخی (`volume_ratio`)
- حداقل ارزش معاملات
- مثبت‌بودن قیمت پایانی
- قدرت خریدار حقیقی، در صورت وجود دادهٔ معتبر

فیلترهای صف خرید/فروش، حجم مشکوک و ورود/خروج پول حقیقی باید پس از تکمیل
market-watch و client-type TSETMC به فیلدهای ساختاریافته وصل شوند؛ نبود داده
نباید به‌عنوان تأیید سیگنال تفسیر شود.

## استراتژی روند-مومنتوم

`trend_momentum_signal` ترکیب EMA سریع/کند و RSI را اجرا می‌کند و علاوه بر
`buy|hold|sell`، دلایل قابل‌توضیح برمی‌گرداند. برای جلوگیری از look-ahead، فقط
اطلاعات تا آخرین کندل استفاده می‌شود و حداقل سابقهٔ لازم کنترل می‌گردد.

## تحلیل بنیادی

`FundamentalMetrics` و `FundamentalAnalyzer` نسبت‌های زیر را با تقسیم امن
محاسبه می‌کنند:

- P/E، P/B و بازده سود نقدی
- حاشیه سود خالص
- بدهی به حقوق صاحبان سهام
- نسبت جاری

دادهٔ بنیادی باید از Codal یا provider معتبر و با دورهٔ گزارش مشخص وارد شود.
در صورت نبود داده، امتیاز خنثی و اعتماد صفر برگردانده می‌شود؛ این تصمیم برای
جلوگیری از امتیازدهی خوش‌بینانه به شرکت‌های فاقد اطلاعات است.

## تنظیمات و استفاده

آستانه‌ها در `configs/filters.yaml` قرار دارند. APIهای برنامه:

```python
app.evaluate_market_filter("فولاد", market="stock")
app.evaluate_strategy("فولاد", market="stock")
app.analyze_fundamentals(metrics)
```

مرحلهٔ بعدی: اتصال market-watch و client-type TSETMC، adapter کدال با دورهٔ
گزارش، و backtest واقعی پیش از فعال‌سازی هر هشدار عملیاتی.
