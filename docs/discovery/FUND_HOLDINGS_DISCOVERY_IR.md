### بررسی ساختار مخزن

- مخزن در commit پایه `6161a318a808a348008a5ef4cb75b034fd64f906` و شاخهٔ `main` پاک بود؛ کار در شاخهٔ مستقل انجام می‌شود.
- در کد فعلی مدل canonical برای صندوق، هویت دارایی، snapshot موقعیت دارایی، رویداد تغییر پرتفوی، provenance و تحلیل مواجهه پیدا نشد. Storage موجود یک cache سبک OHLCV است؛ API و Portal هم پیاده‌سازی نشده‌اند.
- مدل `FundamentalMetrics` و `FundamentalAnalyzer` برای نسبت‌های بنیادی شرکت است و قرارداد پرتفوی صندوق محسوب نمی‌شود.

## موانع Evidence Gate

1. فهرست جامع و رسمی صندوق‌های بورسی و غیربورسی ایران، شناسه پایدار هر صندوق و وضعیت فعالیت/نوع آن هنوز با مرجع اولیه تأیید نشده است.
2. دست‌کم یک منبع رسمیِ قابل دسترسی و مجاز برای گزارش‌های دارای ترکیب دارایی، دوره گزارش، زمان انتشار، اصلاحیه‌ها و فایل خام لازم است. سند حاضر هیچ API یا URL داخلی را حدس نمی‌زند.
3. مالکیت، terms of use، مجوز دانلود/ذخیره‌سازی، استفاده پژوهشی و نمایش در Portal برای CFI، FIPIRAN و CODAL روشن نشده است.
4. schema و هویت canonical فعلی پروژه باید پیش از افزودن مدل موازی به‌طور کامل از مخزن بررسی و توسط مالک/معماری تأیید شود؛ این discovery نشان می‌دهد مدل holding آماده‌ای پیدا نشد، اما پیشنهاد تغییر canonical نمی‌دهد.
5. برای مرحله تحلیل خبر/اقتصاد هنوز منابع اولیهٔ مجاز، طرح نگاشت نماد/ناشر، روش قابل دفاع اثر و آزمون عملکرد/اعتبارسنجی خارج از نمونه تعیین نشده‌اند. تا آن زمان خروجی کمی یا جهت قطعی نباید تولید شود.
6. زمان‌بندی روزانه/هفتگی، سطح تازگی، آرشیو raw و الزامات افشا/محرمانگی هنوز به قرارداد اجرایی تبدیل نشده‌اند.
