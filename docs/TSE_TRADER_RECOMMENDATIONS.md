# پیشنهادهای کارشناسی — تمرکز روی بورس ایران

## دامنه محصول

| نگه دارید | حذف کنید |
|-----------|----------|
| سهام بورس و فرابورس | ارز دیجیتال |
| حق تقدم / اختیار (فاز بعد) | فارکس |
| صندوق‌های بورسی (فاز بعد) | سهام خارجی |
| داده کدال و TSETMC | Binance / Oanda |

## اولویت توسعه

### P0
1. Symbol Master + صنعت
2. Cache-First OHLCV
3. TSETMC پایدار با rate-limit

### P1
4. صف خرید/فروش
5. حجم مشکوک نسبت به میانگین ۲۰ روزه
6. کدال رویدادمحور
7. مقایسه نسبی داخل صنعت

### P2
8. GUI فارسی RTL
9. هشدار صف / حجم
10. بک‌تست با دامنه نوسان و تعطیلات رسمی
