# CR-20261010-001 — کشف هوشمندی دارایی صندوق‌های ایران

**Status:** BLOCKED
**Date:** 2026-10-10
**Scope:** فقط صندوق‌های سرمایه‌گذاری ایران (دامنه چندکشوری در درخواست‌کننده تأیید نشد و کنار گذاشته شد).
**Branch:** `feat/fund-holdings-discovery-iran-20261010`

## Why

کاربر سند اجرایی «Fund Holdings Intelligence Agent & Asset Portal» را ارائه کرد و سپس تأیید کرد دامنه فقط صندوق‌های ایران باشد. قانون اساسی مخزن ایجاب می‌کند قبل از پیاده‌سازی، منبع اولیه، قرارداد داده، مجوز استفاده و شواهد اعتبارسنجی روشن شود؛ در غیر این صورت باید توقف و نیاز شواهد ثبت شود.

## Evidence

1. baseline مخزن `6161a318a808a348008a5ef4cb75b034fd64f906` و فایل‌های `AGENTS.md`، قانون اساسی، چک‌لیست شروع، دفتر تغییرات، change recordهای اخیر، ADR داده روزانه بورس، registry منابع و معماری بررسی شد.
2. پوشه Drive ارائه‌شده با ID `1VV4bepF0i33q-4pco15BvMSCmeDBEh4h` و فایل `سبد گردانان بورس.xlsx` با ID `1LkXtSGYLlxvLY3lewnAX9MNhKJQraeFj` از Drive API خوانده شدند. Drive metadata، MD5، SHA-256 و نتایج شمارش ساختار در `docs/discovery/FUND_HOLDINGS_DISCOVERY_IR.md` و `docs/sources/DRIVE_SOURCE_REGISTRY.md` ثبت شده‌اند.
3. فایل دارای 130 ردیف نهاد در پنج نوع، از جمله 97 سبدگردان، و 130 پیوند جزئیات به `cfi.seo.ir` است؛ این داده معادل فهرست جامع صندوق‌ها یا گزارش ترکیب دارایی آن‌ها نیست. صحت/جامعیت و شرایط استفاده مستقل تأیید نشده است.
4. fetch صفحات فیپیران/صفحه مقرراتی محتوای قابل استخراج نداد؛ مرورگر فیپیران با اتصال بسته‌شده روبه‌رو شد؛ میزبان CFI در fetch resolve نشد؛ CODAL پاسخ مسدودسازی امنیتی برگرداند. هیچ دسترسی‌ای دور زده نشد.
5. جست‌وجوی baseline کد holding schema/repository، API یا Portal آماده‌ای نشان نداد. مدل بنیادی شرکت موجود، قرارداد پرتفوی صندوق نیست. ADR موجود فقط تصمیم Provider قیمت روزانه TSETMC را پوشش می‌دهد.

## Change

- گزارش discovery ایران اضافه شد.
- وضعیت منبع Drive جدید و metadata قابل ردیابی در Source Registry ثبت شد، بدون اینکه محتوا VERIFIED معرفی شود.
- Change Ledger به‌روز شد.
- **هیچ کد، adapter، API، UI، job، schema canonical، داده مصنوعی، تحلیل عددی، سیگنال معامله یا اتصال معاملاتی اضافه نشد.**

## Validation

- XLSX با `openpyxl` باز شد؛ تعداد ردیف‌ها، دسته‌بندی نوع، فیلدهای خالی، یکتایی نام‌ها، پیوندها و checksumها بررسی شدند.
- `git diff --check` باید پیش از commit/PR پاس شود.
- تست‌های pytest اجرا نشدند؛ محیط فعال ماژول `pytest` ندارد و تغییر مستنداتی است. این محدودیت نباید به‌عنوان موفقیت آزمون گزارش شود.

## Risk / Blocker

منبع رسمیِ قابل دسترسی و مجاز برای گزارش واقعی ترکیب دارایی و schema/version/revision آن تأیید نشده است. شروط استفاده و ذخیره‌سازی/بازنمایش نیز روشن نیست. ایجاد adapter یا گزارش‌گیری زمان‌بندی‌شده اکنون مستلزم حدس می‌شود و با قانون اساسی پروژه تعارض دارد.

## Required next step

مالک/کاربر باید دسترسی یا سند/API رسمی و مجاز همراه با فایل خام واقعی، دوره گزارش، زمان انتشار، URL/شناسه، شروط استفاده و مشخصات نسخه/اصلاحیه را فراهم کند. پس از آن، inventory منبع و صندوق‌ها و بررسی قرارداد canonical ادامه می‌یابد؛ هر تصمیم معماری جدید به تأیید مالک نیاز دارد.

## Decision

**BLOCKED — Phase A incomplete.** دامنه ایران تأیید شده است، اما تا دریافت شواهد منبع اولیه و مجاز، پیاده‌سازی متوقف می‌ماند.
