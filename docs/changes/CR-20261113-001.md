## مسئله و انگیزه

ARYA دارای پایپ‌لاین مستقل Provider → Analysis → Scoring → Rule-based Decision → Independent Risk → Recommendation است. TradingAgents یک چارچوب مستقل multi-agent است. جایگزینی مستقیم هسته ARYA، تزریق rating زبانی به امتیاز کمی، یا وابسته‌کردن مسیر TSETMC به ابزار خارجی با معماری فعلی سازگار نیست.

## دامنه تغییر

- افزودن adapter اختیاری و lazy-loaded در src/arya/ai/agents/tradingagents_adapter.py.
- افزودن runner مستقل scripts/run_tradingagents_research.py.
- pin کردن wheel انتشار رسمی TradingAgents در requirements-tradingagents.txt؛ نصب آن به dependencyهای پایه ARYA اضافه نمی‌شود.
- افزودن unit tests آفلاین با stub در tests/ai/test_tradingagents_adapter.py.
- ثبت مستندات مرزبندی، نصب، اجرا و محدودیت‌ها در docs/integrations/TRADINGAGENTS.md.

## تصمیم‌های ایمنی/معماری

- خروجی upstream به‌صورت rating دسته‌ای مستقل نگه داشته می‌شود؛ هیچ نگاشت عددی یا تزریق خودکار به Decision، RiskAssessment یا Recommendation وجود ندارد.
- REVIEW به‌جای HOLD نگه داشته می‌شود.
- international_stock و crypto تنها asset classهای فعال هستند. بورس ایران/TSETMC و forex صریحاً رد می‌شوند.
- TradingAgents از data-providerهای خودش استفاده می‌کند؛ داده ARYA به آن تزریق نمی‌شود. خروجی یک نظر پژوهشی دوم است و به معنی تأیید داده یا سیگنال نیست.
- گزارش، کش و memory log در ~/.arya/tradingagents/ نگه‌داری می‌شوند، نه در پوشه داده trackشده پروژه.
- هیچ credential، API key، order service، broker adapter یا live trading افزوده نشده است.
- کد upstream کپی نشده؛ فقط API عمومی استفاده شده است. نسخه upstream v0.7.1 با مجوز Apache-2.0 از انتشار رسمی pin شده است.
