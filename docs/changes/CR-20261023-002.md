1. `MarketDataSafetyError` و guard مرکزی افزوده شد: Provider غیرفعال رد می‌شود؛ driver=`mock` در حالت پیش‌فرض قبل از دریافت/نمایش داده رد می‌شود.
2. فقط آزمون‌های واحد می‌توانند با `AryaApp(..., allow_mock_data=True)` به‌صورت صریح mock را فعال کنند. گزینه‌ای برای دورزدن guard به CLI عملیاتی افزوده نشد.
3. CLI خطا را با پیام فارسی و exit code برابر 2 گزارش می‌کند.
4. تست‌های default-deny، اولویت `enabled: false` و مدیریت خطای CLI اضافه شد؛ fixtureهای deterministic موجود به اجازهٔ صریح تستی به‌روزرسانی شدند.
