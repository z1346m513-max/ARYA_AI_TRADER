# تصمیم معماری ۰۰۱: فاز اول دادهٔ آنلاین بورس ایران

**وضعیت:** پذیرفته‌شده  
**تاریخ:** ۲۰۲۶-۱۰-۰۲

## زمینه

نسخهٔ اولیهٔ پروژه پایپ‌لاین تحلیل را با `MockMarketProvider` اجرا می‌کرد و برای
ساخت پلتفرم واقعی دادهٔ آنلاین نداشت. اولویت پروژه، بورس ایران است و باید
اتصال داده از لایه‌های تحلیل مستقل بماند تا بازارهای کریپتو، فارکس و سهام خارجی
بعداً بدون بازنویسی هسته اضافه شوند.

## تصمیم‌ها

1. قرارداد `MarketDataProvider` حفظ می‌شود و `TsetmcMarketProvider` به‌عنوان
   پیاده‌سازی بازار `stock` اضافه می‌شود.
2. TSETMC از طریق endpointهای JSON عمومی و بدون API key مصرف می‌شود؛ `User-Agent`،
   timeout، retry با backoff و خطای قابل‌تشخیص برای پاسخ نامعتبر الزامی است.
3. در این مرحله timeframe عملیاتی TSETMC فقط روزانه (`1d`) است. پشتیبانی intraday
   پس از مشخص‌شدن منبع پایدار و قرارداد دادهٔ آن اضافه می‌شود.
4. `MockMarketProvider` برای تست‌های deterministic باقی می‌ماند؛ تست‌های واحد
   نباید به شبکه یا بازار زنده وابسته باشند.
5. درایور پیش‌فرض بورس ایران `tsetmc` است، اما provider و endpoint از YAML قابل
   تغییرند تا استقرار آزمایشی، fallback و محیط تست ممکن بماند.
6. نسخهٔ بسته به قالب معتبر PEP 440 اصلاح شد تا `pip install -e .` قبل از اجرای
   برنامه شکست نخورد.

## خارج از محدوده

مالیات و هر قابلیت مالیاتی در این پروژه پیاده‌سازی یا مستندسازی نمی‌شود.

## پیامدها و کارهای بعدی

- شبکهٔ استقرار باید دسترسی به `cdn.tsetmc.com` و سیاست rate limit مناسب داشته باشد.
- مرحلهٔ بعد باید freshness، market-hours، market-watch bulk refresh، ثبت منبع و
  پایش خطا را به scheduler و storage اضافه کند.
- اتصال Binance، فارکس و سهام خارجی باید همین قرارداد provider را رعایت کند.
- پیش از استفادهٔ عملیاتی، کیفیت دادهٔ نمادها، تعطیلات بازار و رفتار endpoint در
  IP استقرار باید جداگانه اعتبارسنجی شود.
