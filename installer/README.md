# نصب‌کننده ویندوز (Milestone 5)

برنامه‌ریزی برای بسته‌بندی نسخه‌ی نصبی ویندوز:

1. **Freeze کردن اپلیکیشن**: PyInstaller یا Nuitka برای تبدیل GUI (PySide6) به یک
   اجرایی مستقل (`ARYA.exe`).
2. **Setup.exe**: استفاده از [Inno Setup](https://jrsoftware.org/isinfo.php) برای
   ساخت نصب‌کننده‌ی حرفه‌ای با:
   - آیکون اختصاصی (`installer/icon/`)
   - میانبر دسکتاپ و منوی استارت
   - مسیر نصب قابل انتخاب
   - حذف‌کننده (Uninstaller)
3. **به‌روزرسانی خودکار**: بررسی نسخه‌ی جدید از یک endpoint ساده و دانلود/جایگزینی
   نصب‌کننده‌ی جدید.

این مرحله نیازمند محیط Windows برای Build و تست واقعی است و در Milestone 5،
پس از تکمیل GUI (Milestone 4)، انجام می‌شود.
